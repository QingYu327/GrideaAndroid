常见问题

备份与恢复

Gridea Android 的所有数据都存在本地应用沙箱内，不上传任何服务器。BackupScheduler 会周期性为你备份全部内容，你也可以手动导出，换机或重装时一键恢复。

备份范围

一次完整备份包含以下内容：

类别内容
文章全部已发布 / 草稿 / 回收站文章及版本历史
标签所有标签定义
友链友链列表
菜单自定义菜单项
主题配置当前主题选择与 customConfig 配置值
偏好设置站点信息、部署凭证、界面偏好等 DataStore 配置

自动备份

BackupScheduler 调度周期性备份任务，默认每天在后台执行一次。你可以在「设置 → 备份」中：

  • 开启 / 关闭自动备份。
  • 调整备份频率。
  • 设置保留份数（超过后自动清理最旧的备份）。

备份文件存储在应用沙箱目录下，卸载应用会一并清除。重要数据建议定期手动导出到外部存储或云盘。

手动导出

在「设置 → 备份 → 立即备份并导出」可生成一份完整备份包，通过系统分享面板保存到：

  • 本地下载目录。
  • 云盘 App（如 Google Drive、OneDrive、百度网盘）。
  • 通过邮件或即时通讯发送给自己。

备份包是标准的压缩归档，可单独解压查看其中的 Markdown 原文，不依赖 App 即可阅读你的文章。

恢复数据

换机或重装后，可通过备份包恢复：

  1. 安装并打开 Gridea Android，完成首次引导。
  2. 进入「设置 → 备份 → 从文件恢复」。
  3. 选择之前导出的备份包。
  4. App 会校验包完整性，并列出可恢复的内容供你确认。
  5. 确认后恢复完成，文章、标签、主题配置、部署凭证等全部回到备份时的状态。

注意：恢复操作会用备份内容覆盖当前数据。如果当前有未备份的新内容，请先导出一份再恢复。

隐私说明

  • 所有文章、配置、主题数据均存储在应用沙箱内，其他应用无法访问。
  • 部署时仅与你配置的代码托管平台通信。
  • 部署凭证（Token、私钥）保存在 DataStore 中，未加密但隔离于其他应用。
  • 反馈日志打包前会脱敏处理（token 等敏感字段仅保留前缀），详见 日志管理。
