常见问题

文章管理

文章是博客的核心。Gridea Android 提供完整的文章生命周期管理：创建、编辑、标签、封面图、草稿、回收站与版本历史，全部在手机本地完成。

创建与编辑

在「文章」标签页点击右下角 FAB 按钮新建文章。编辑器基于 Markwon 引擎，支持完整的 Markdown 语法与多项扩展。

支持的 Markdown 语法

  • 基础语法：标题、粗体、斜体、删除线、引用、有序 / 无序列表、链接、图片、分割线、表格。
  • 代码：行内代码与围栏代码块，支持语法高亮。
  • 任务列表：- [ ] 与 - [x]。
  • 上下标：H~2~O、x^2^。
  • 高亮标记：==高亮文字==。
  • 数学公式：通过主题配置开启。
## 一段示例

普通段落，含 **粗体**、*斜体*、~~删除线~~、==高亮==。

- [x] 已完成事项
- [ ] 待办事项

行内代码 `print("hello")`，代码块：

```python
def greet(name):
    return f"Hello, {name}!"
```

自动保存与手动保存

编辑器在你停笔 2 秒后自动保存到 Room 数据库；离开编辑页面时，会用 NonCancellable 协程兜底，确保最后一个字也不会丢失。顶部保存按钮可随时手动触发保存。

查找替换

编辑器内置 IDE 风格的查找替换面板：

  • 所有匹配项以浅黄背景高亮。
  • 当前匹配项用深黄背景 + 斜体突出显示。
  • 切换匹配时编辑器自动滚动定位。
  • 输入采用 220ms 防抖，避免长文章卡顿。

封面图

点击编辑器顶部工具栏的封面图按钮，可从相册选取图片作为文章封面。封面图会随文章一起部署，并在支持封面的主题（如瀑布流、杂志）首页以卡片形式展示。

建议：封面图推荐 16:9 或 3:2 比例，体积控制在 500KB 以内以加快加载。

标签

标签用于组织文章，每篇文章可挂多个标签。在编辑页的标签栏输入并回车即可创建或选用已有标签。标签页会自动聚合所有文章，主题中的 tags.peb 与 tag.peb 模板负责渲染标签云与标签下的文章列表。

  • 新建标签：在标签栏直接输入名称回车。
  • 管理标签：在「标签」标签页可重命名或删除标签。
  • 删除标签不会删除文章，只是解除关联。

草稿与回收站

文章有三种状态：已发布、草稿、已删除。

状态是否部署是否计入统计
已发布是是
草稿否否
已删除（回收站）否否

在文章列表左滑或长按可将文章移入回收站。回收站中的文章可恢复或彻底删除。彻底删除后不可恢复（但若已开启备份，可从备份中还原，见 备份与恢复）。

版本历史

编辑器每 2 分钟为文章生成一次版本快照。在文章详情页可查看全部历史版本，并随时回滚到任意历史版本。版本数据独立存储，回滚不会丢失当前内容（会作为新版本保留）。

写作统计

每篇文章会自动记录写作时长，配合字数目标进度条量化输出节奏。在「统计」标签页可查看：

  • 写作热力图：按日展示写作活跃度。
  • 字数统计：总字数、平均字数、最长文章。
  • 文章分析：按标签、按月份的分布。
