常见问题

主题系统

Gridea Android 使用 Pebble 模板引擎（替代原版的 EJS）渲染站点。应用内置 7 套主题，同时支持通过 .zip 包导入自定义主题。主题与 App 之间通过 theme.json 通信。

内置主题

应用内置 7 套主题，均强制要求响应式适配（手机端 ≤768px 与电脑端）：

主题标识风格
杂志编辑magazine大标题、网格排版、图文专栏
复古打字机retro等宽字体、米色纸张、怀旧质感
瀑布流masonry封面优先、不规则卡片、视觉博客
经典双栏sidebar侧边栏导航、技术博客、友链
终端terminal单色高对比、极客风、等宽
水墨ink东方意境、衬线字体、诗文随笔

在「主题」标签页点击任意主题卡片即可切换。切换后预览界面立即重新渲染，无需重新部署。

导入自定义主题

除内置主题外，你可以导入他人分享或自己开发的主题包。主题包是一个 .zip 文件，结构如下：

my-theme.zip
├── theme.json          # 主题配置契约（必需）
├── preview.jpg         # 主题预览图（必需）
├── base.peb            # 基础布局模板（必需）
├── index.peb           # 首页
├── post.peb            # 文章页
├── tag.peb             # 标签文章列表
├── tags.peb            # 标签云
├── archives.peb        # 归档页
├── friends.peb         # 友链页
├── 404.peb             # 404 页
├── custom.css          # 附加样式（可选）
├── custom.js           # 附加脚本（可选）
└── assets/             # 附加资源（可选）
    ├── font/
    ├── image/
    └── ...

导入步骤：「主题」页 → 右上角导入按钮 → 选择 .zip 文件 → 应用自动校验并安装。安装后可在主题列表中看到新主题。

主题开发

模板引擎：Pebble

Gridea Android 使用 Pebble 模板引擎。语法示例：

{# base.peb #}
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>{{ site.title }}</title>
  <link rel="stylesheet" href="{{ theme.assets.customCss }}">
</head>
<body>
  <header>
    <a href="{{ site.url }}">{{ site.title }}</a>
  </header>

  {% block content %}{% endblock %}

  <footer>© {{ site.author }}</footer>
</body>
</html>
{# index.peb #}
{% extends "base.peb" %}

{% block content %}
  <main>
    {% for post in posts %}
      <article>
        <h2><a href="{{ post.url }}">{{ post.title }}</a></h2>
        <time>{{ post.date }}</time>
        <p>{{ post.summary }}</p>
      </article>
    {% endfor %}
  </main>
{% endblock %}

可用模板变量

变量说明
site.title站点标题
site.description站点描述
site.url站点 URL
site.author作者昵称
posts已发布文章列表（首页 / 归档）
post.title / post.content / post.url单篇文章字段
post.date / post.tags / post.cover文章日期 / 标签 / 封面
tags全部标签
menus自定义菜单项
friends友链列表
theme.config.xxx通过 theme.json 声明的自定义配置

theme.json 配置契约

theme.json 是主题与 App 之间的通信契约。它声明主题元信息与用户可配置项，App 会根据 customConfig 自动生成配置界面。

{
  "name": "我的主题",
  "author": "Your Name",
  "version": "1.0.0",
  "description": "一个示例主题",
  "preview": "preview.jpg",
  "customConfig": [
    {
      "name": "accentColor",
      "label": "主题色",
      "type": "text",
      "default": "#059669"
    },
    {
      "name": "showSidebar",
      "label": "显示侧边栏",
      "type": "switch",
      "default": true
    },
    {
      "name": "columns",
      "label": "列数",
      "type": "slider",
      "min": 1, "max": 4, "step": 1, "default": 2
    },
    {
      "name": "customCss",
      "label": "自定义 CSS",
      "type": "code",
      "default": ""
    },
    {
      "name": "tags",
      "label": "显示的标签",
      "type": "multiselect",
      "options": ["tech", "life", "photo"],
      "default": ["tech"]
    }
  ]
}

支持的控件类型（type）共 5 种：

类型说明额外字段
text单行文本—
switch布尔开关—
slider数值滑块min / max / step
code多行代码—
multiselect多选options

配置值在模板中通过 {{ theme.config.accentColor }} 访问。用户修改配置后预览立即重新渲染。

附加资源

主题包可声明附加资源，App 会自动复制到输出目录并按需注入 HTML：

  • css / js：custom.css 与 custom.js 自动注入到页面。
  • font：字体文件，通过 @font-face 引用。
  • image / file：图片与其他静态文件，模板中通过 {{ theme.assets.xxx }} 引用路径。

响应式强制要求：每个主题必须同时适配手机端（≤768px）与电脑端（>768px）。审核主题时会检查移动端表现。

主题调试

开发主题时，建议开启「设置 → 调试模式 → WebView 远程调试」，然后用 Chrome 浏览器访问 chrome://inspect 远程审查预览页。App 内置的 JS Bridge 会把页面点击、控制台日志、资源加载失败、404 等事件回传到 AppLogger，无需 logcat 即可定位问题，详见 日志管理。
