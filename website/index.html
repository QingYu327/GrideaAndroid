核心功能

为写作者精心打磨的细节

不需要命令行，不需要繁琐配置。打开 App，即刻开始写作。

✍️

Markdown 写作

基于 Markwon 引擎，支持代码高亮、任务列表、上下标与高亮标记。IDE 风格查找替换，2 秒自动保存，版本历史随时回滚。

👁️

实时预览

WebView 加载本地构建产物，与浏览器表现完全一致。修改主题配置立即重新渲染，所见即所得，无需重新部署。

🎨

主题系统

Pebble 模板引擎 + theme.json 配置契约，6 款内置主题覆盖杂志、终端、水墨等风格，三端响应式，支持自定义主题包导入。

🚀

一键部署

直连 GitHub Pages、Gitee、SFTP、Netlify、Vercel 五大平台。后台 Service 执行构建上传，支持中断、进度通知与失败重试。

🔒

全本地隐私

所有数据存储在应用沙箱内，不上传任何服务器。Room 数据库 + DataStore 持久化，反馈日志打包前自动脱敏。

✨

Material You

100% Jetpack Compose 实现，动态取色跟随系统壁纸，灵动岛通知、手势导航、FAB 按压动画，中英双语，亮色暗色自由切换。
